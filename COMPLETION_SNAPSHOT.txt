✨ ARCHITECTURE HIGHLIGHTS
─────────────────────────────────────────────────────────────────────────────

✅ ZERO EXPRESS CODE IN SERVICES
   • Services are pure functions
   • NO req/res objects
   • NO middleware
   • Can be tested without HTTP framework

✅ CLEAN LAYER SEPARATION
   • Route: Validation & response formatting
   • Service: Business logic & data operations
   • Utility: Common helpers (logging, etc)

✅ MAXIMUM REUSABILITY
   • Services usable from: HTTP routes, CLI, cron jobs, webhooks
   • No HTTP context required
   • Easy to test and mock

✅ SECURITY
   • Path traversal protection in image serving
   • Input validation in all routes
   • Safe file operations

✅ CROSS-PLATFORM
   • Windows: PowerShell folder picker
   • macOS: AppleScript folder picker
   • Linux: zenity/kdialog support

✅ ERROR HANDLING
   • Try-catch in all operations
   • Graceful degradation
   • Comprehensive logging

✅ DOCUMENTATION
   • JSDoc comments on all functions
   • Clear variable names
   • Architecture guides created

🎯 DATA FLOW EXAMPLE
─────────────────────────────────────────────────────────────────────────────

Request: POST /api/reviews { title: "New Review" }
  ↓
reviewsRoutes.js (HTTP handler)
  ├─ Validate: req.body.title exists? ✓
  ├─ Call: reviewsService.createReview(req.body)
  └─ Return: res.status(201).json(review)
  ↓
reviewsService.js (Business logic)
  ├─ this.readReviews() via fileSystemService
  ├─ Calculate nextId = 5
  ├─ Create review object with timestamps
  ├─ this.writeReviews() via fileSystemService
  └─ logger.info() via logger utility
  ↓
fileSystemService.js & logger.js (Utilities)
  ├─ fs.readFileSync(dataFile)
  ├─ JSON.parse() / JSON.stringify()
  ├─ fs.writeFileSync(dataFile)
  └─ console.log() with formatting
  ↓
Response: { "id": 5, "title": "...", "createdAt": "..." }
