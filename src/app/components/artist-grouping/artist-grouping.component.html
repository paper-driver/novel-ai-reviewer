Group Images by Artist Tags

This tool analyzes image metadata to extract artist tags and groups images based on their artist tag combinations. Select a source folder containing images (PNG, JPG, WebP) and a destination folder where sorted subfolders will be created.

Note: Supported formats: PNG (with metadata), JPG, WebP. macOS system files (starting with ._) will be automatically skipped.
